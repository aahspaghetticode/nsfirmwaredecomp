대상 제품에 대하여

다음 제품에 관한 주의사항을 기재하였습니다.

  • Nintendo Switch 패밀리 [HEG-001] / [HAC-001] / [HDH-001]
    각각의 본체에 배터리가 내장되어 있습니다.
  • Nintendo Switch AC 어댑터 [HAC-002(KOR)]
    다음 기기에 사용합니다.
    • Nintendo Switch 패밀리 [HEG-001] / [HAC-001] / [HDH-001]
    • Nintendo Switch 독 [HEG-007] / [HAC-007]
    • Joy-Con 충전 그립 [HAC-012]
    • Nintendo Switch Pro 컨트롤러 [HAC-013]
    • Nintendo Switch 충전 스탠드(프리 스톱 방식) [HAC-031]
    • 카트 [HAC-037]
    • Super Nintendo Entertainment System 컨트롤러 [HAC-042]
    • Nintendo 64 컨트롤러 [HAC-043]
    • SEGA Mega Drive Fighting Pad 6B [HAC-046]
    • Joy-Con 충전 스탠드(2way) [HAC-048]
  • Joy-Con(L) [HAC-015] / Joy-Con(R) [HAC-016]
    본체 [HEG-001] / [HAC-001]에 장착/분리할 수 있는 컨트롤러입니다.
    배터리가 내장되어 있습니다.
  • Nintendo Switch 독 [HEG-007] / [HAC-007]
    본체 [HEG-001] / [HAC-001]를 TV에 연결할 때 사용합니다.
  • 고속 HDMI® 케이블 [HEG-005] / [WUP-008]
  • 게임 카드 [HAC-008] / 카드 케이스 [HAC-009]
    Nintendo Switch용 게임 소프트웨어입니다.
  • Joy-Con 그립 [HAC-011]
    Joy-Con을 장착하여 사용합니다.
  • Joy-Con 충전 그립 [HAC-012]
    Joy-Con을 장착하여 사용합니다. Nintendo Switch AC 어댑터 [HAC-002(KOR)]나 USB 충전 케이블 [HAC-010]을 연결하여 Joy-Con을 충전시킬 수도 있습니다.
  • Nintendo Switch Pro 컨트롤러 [HAC-013]
    Nintendo Switch용 컨트롤러입니다. 배터리 [CTR-003]가 내장되어 있습니다.
  • USB 충전 케이블 [HAC-010]
    다음 기기에 사용합니다.
    • Nintendo Switch 독 [HEG-007] / [HAC-007]
    • Joy-Con 충전 그립 [HAC-012]
    • Nintendo Switch Pro 컨트롤러 [HAC-013]
    • 몬스터볼 Plus [HAC-024]
    • 카트 [HAC-037]
    • Super Nintendo Entertainment System 컨트롤러 [HAC-042]
    • Nintendo 64 컨트롤러 [HAC-043]
    • SEGA Mega Drive Fighting Pad 6B [HAC-046]
    • Joy-Con 충전 스탠드(2way) [HAC-048]
  • Joy-Con 스트랩 [HAC-014]
    Joy-Con에 장착하여 사용합니다.
  • Joy-Con 핸들 [HAC-017]
    Joy-Con을 장착하여 핸들형 컨트롤러로 사용합니다.
  • Nintendo Switch 충전 스탠드(프리 스톱 방식) [HAC-031]
    화면의 각도를 자유롭게 조절할 수 있는 테이블 모드용 스탠드입니다. AC 어댑터 [HAC-002(KOR)]를 연결하여 본체를 충전할 수도 있습니다.
  • Nintendo Entertainment System 컨트롤러(L) [HAC-033] /
    Nintendo Entertainment System 컨트롤러(R) [HAC-034]
    『Nintendo Entertainment System - Nintendo Switch Online』에서 사용 가능한 컨트롤러입니다. 본체 [HEG-001] / [HAC-001] 또는 Joy-Con 충전 스탠드(2way) [HAC-048]에 장착하여 충전합니다.
  • Nintendo Switch 터치펜 [HAC-040] / [HAC-041]
  • Super Nintendo Entertainment System 컨트롤러 [HAC-042]
    『Super Nintendo Entertainment System - Nintendo Switch Online』에서 사용 가능한 컨트롤러입니다.
  • Nintendo 64 컨트롤러 [HAC-043]
    『Nintendo 64 – Nintendo Switch Online』에서 사용 가능한 컨트롤러입니다.
  • SEGA Mega Drive Fighting Pad 6B [HAC-046]
    『SEGA Mega Drive – Nintendo Switch Online』에서 사용 가능한 컨트롤러입니다.
  • Joy-Con 충전 스탠드(2way) [HAC-048]
    Joy-Con 또는 Nintendo Entertainment System 컨트롤러를 충전할 수 있습니다.
  • microSD/microSDHC/microSDXC 메모리 카드
