対象製品について

次の製品に関する注意事項を記載しています。

  • Nintendo Switchファミリー [HEG-001] / [HAC-001] / [HDH-001]
    それぞれの本体にバッテリーが内蔵されています。
  • Nintendo Switch ACアダプター [HAC-002(JPN)]
    次の機器に使用します。
    • Nintendo Switchファミリー [HEG-001] / [HAC-001] / [HDH-001]
    • Nintendo Switchドック [HEG-007] / [HAC-007]
    • Joy-Con充電グリップ [HAC-012]
    • Nintendo Switch Proコントローラー [HAC-013]
    • Nintendo Switch充電スタンド（フリーストップ式） [HAC-031]
    • カート [HAC-037]
    • スーパーファミコン コントローラー [HAC-042]
    • NINTENDO 64 コントローラー [HAC-043]
    • セガ メガドライブ ファイティングパッド 6B [HAC-046]
    • Joy-Con充電スタンド（2way） [HAC-048]
  • Joy-Con(L) [HAC-015] / Joy-Con(R) [HAC-016]
    本体 [HEG-001] / [HAC-001] に取り付け/取り外しができるコントローラーです。バッテリーが内蔵されています。
  • Nintendo Switchドック [HEG-007] / [HAC-007]
    本体 [HEG-001] / [HAC-001] をテレビに接続するときに使用します。
  • ハイスピードHDMI®ケーブル [HEG-005] / [WUP-008]
  • ゲームカード [HAC-008] / カードケース [HAC-009]
    Nintendo Switch用のゲームソフトです。
  • Joy-Conグリップ [HAC-011]
    Joy-Conを取り付けて使用します。
  • Joy-Con充電グリップ [HAC-012]
    Joy-Conを取り付けて使用します。 Nintendo Switch ACアダプター [HAC-002(JPN)] やUSB充電ケーブル [HAC-010] を接続してJoy-Conを充電することもできます。
  • Nintendo Switch Proコントローラー [HAC-013]
    Nintendo Switch用のコントローラーです。バッテリーが内蔵されています。
  • USB充電ケーブル [HAC-010]
    次の機器に使用します。
    • Nintendo Switchドック [HEG-007] / [HAC-007]
    • Joy-Con充電グリップ [HAC-012]
    • Nintendo Switch Proコントローラー [HAC-013]
    • モンスターボールPlus [HAC-024]
    • カート [HAC-037]
    • スーパーファミコン コントローラー [HAC-042]
    • NINTENDO 64 コントローラー [HAC-043]
    • セガ メガドライブ ファイティングパッド 6B [HAC-046]
    • Joy-Con充電スタンド（2way） [HAC-048]
  • Joy-Conストラップ [HAC-014]
    Joy-Conに取り付けて使用します。
  • Joy-Conハンドル [HAC-017]
    Joy-Conを取り付けてハンドル型のコントローラーとして使用します。
  • Joy-Con(L)拡張バッテリー（乾電池式） [HAC-019] /
    Joy-Con(R)拡張バッテリー（乾電池式） [HAC-020]
    単3形アルカリ乾電池でJoy-Con(L)/(R)の充電（給電）ができます。
  • Nintendo Switch充電スタンド（フリーストップ式） [HAC-031]
    画面の角度を自由に変えられるテーブルモード用のスタンドです。ACアダプター [HAC-002(JPN)] を接続して本体を充電することもできます。
  • ファミリーコンピュータ コントローラー(Ⅰ) [HAC-035] /
    ファミリーコンピュータ コントローラー(Ⅱ) [HAC-036]
    『ファミリーコンピュータ Nintendo Switch Online』で使えるコントローラーです。本体 [HEG-001] / [HAC-001] やJoy-Con充電スタンド(2way) [HAC-048] に取り付けて充電します。
  • Nintendo Switchタッチペン [HAC-040] / [HAC-041]
  • スーパーファミコン コントローラー [HAC-042]
    『スーパーファミコン Nintendo Switch Online』で使えるコントローラーです。
  • NINTENDO 64 コントローラー [HAC-043]
    『NINTENDO 64 Nintendo Switch Online』で使えるコントローラーです。
  • セガ メガドライブ ファイティングパッド 6B [HAC-046]
    『セガ メガドライブ for Nintendo Switch Online』で使えるコントローラーです。
  • Joy-Con充電スタンド(2way) [HAC-048]
    Joy-Conやファミリーコンピュータ コントローラーの充電ができます。
  • microSD/microSDHC/microSDXCメモリーカード
