關於對象產品

以下列出各產品的注意事項。以「※」標註的產品僅於香港地區售賣。

  • Nintendo Switch家族 [HEG-001] / [HAC-001] / [HDH-001]
    各款主機內置充電池。
  • Nintendo Switch AC變壓器 [HAC-002(UKV) / HAC-002(USZ)]
    適用於以下設備。
    • Nintendo Switch家族 [HEG-001] / [HAC-001] / [HDH-001]
    • Nintendo Switch底座 [HEG-007] / [HAC-007]
    • Joy-Con充電握把 [HAC-012]
    • Nintendo Switch Pro控制器 [HAC-013]
    • Nintendo Switch充電支架（轉軸式） [HAC-031]
    • 賽車 [HAC-037]
    • Super Famicom控制器 [HAC-042]※
    • Nintendo 64控制器 [HAC-043]※
    • SEGA Mega Drive Fighting Pad 6B [HAC-046]※
    • Joy-Con充電支架（多用途） [HAC-048]
  • Joy-Con(L) [HAC-015] / Joy-Con(R) [HAC-016]
    可安裝到主機 [HEG-001] / [HAC-001] 或從主機 [HEG-001] / [HAC-001] 取下的控制器，內置充電池。
  • Nintendo Switch底座 [HEG-007] / [HAC-007]
    把主機 [HEG-001] / [HAC-001] 連接到電視時使用。
  • High Speed HDMI® Cable [HEG-005] / [WUP-008]
  • 遊戲卡 [HAC-008] / 卡盒 [HAC-009]
    Nintendo Switch使用的遊戲軟體。
  • Joy-Con握把 [HAC-011]
    把Joy-Con安裝在其上使用。
  • Joy-Con充電握把 [HAC-012]
    把Joy-Con安裝在其上使用。 可連接Nintendo Switch AC變壓器 [HAC-002(UKV) / HAC-002(USZ)] 或USB充電線 [HAC-010] 為Joy-Con充電。
  • Nintendo Switch Pro控制器 [HAC-013]
    Nintendo Switch使用的控制器，內置充電池。
  • USB充電線 [HAC-010]
    適用於以下設備。
    • Nintendo Switch底座 [HEG-007] / [HAC-007]
    • Joy-Con充電握把 [HAC-012]
    • Nintendo Switch Pro控制器 [HAC-013]
    • 精靈球 Plus [HAC-024]
    • 賽車 [HAC-037]
    • Super Famicom控制器 [HAC-042]※
    • Nintendo 64控制器 [HAC-043]※
    • SEGA Mega Drive Fighting Pad 6B [HAC-046]※
    • Joy-Con充電支架（多用途） [HAC-048]
  • Joy-Con腕帶 [HAC-014]
    安裝在Joy-Con上使用。
  • Joy-Con方向盤 [HAC-017]
    把Joy-Con安裝在其上，作為方向盤型控制器使用。
  • Joy-Con(L)擴張電池（乾電池） [HAC-019] /
    Joy-Con(R)擴張電池（乾電池） [HAC-020]
    可利用AA乾電池為Joy-Con(L)/(R)充電或供電。
  • Nintendo Switch充電支架（轉軸式） [HAC-031]
    可自由改變螢幕角度的桌上模式專用支架。可連接AC變壓器 [HAC-002(UKV) / HAC-002(USZ)] 為主機充電。
  • Family Computer控制器(Ⅰ) [HAC-035]※ /
    Family Computer控制器(Ⅱ) [HAC-036]※
    可於『Family Computer Nintendo Switch Online』上使用的控制器。安裝到主機 [HEG-001] / [HAC-001] 或Joy-Con充電支架（多用途） [HAC-048] 進行充電。
  • Nintendo Switch觸控筆 [HAC-040] / [HAC-041]※
  • Super Famicom控制器 [HAC-042]※
    可於『Super Famicom Nintendo Switch Online』上使用的控制器。
  • Nintendo 64控制器 [HAC-043]※
    可於『Nintendo 64 - Nintendo Switch Online』上使用的控制器。
  • SEGA Mega Drive Fighting Pad 6B [HAC-046]※
    可於『SEGA Mega Drive - Nintendo Switch Online』上使用的控制器。
  • Joy-Con充電支架（多用途） [HAC-048]
    可為Joy-Con或Family Computer控制器充電。
  • microSD/microSDHC/microSDXC記憶卡
